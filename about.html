What is Live Poker Tracker?

Live Poker Tracker is a free, browser-based chip manager designed for home poker games, tournaments, and cash games. Whether you're hosting a Texas Hold'em tournament or a casual poker night, it tracks chip stacks, calculates pots, manages blinds, and monitors betting action in real-time — no download or registration required.

Stop wasting time on mental math and chip disputes. Focus on playing cards while the tracker handles everything automatically: pot totals, bet sizes, blind posting, side pots, and hand history. Just open your browser on any device and start playing.

Key Features

Free Poker Chip Calculator

Our poker chip calculator manages player stacks and chip counts effortlessly. Add players with starting stacks, and the free poker tracker automatically calculates and updates chip counts as the game progresses. This digital poker chip counter eliminates arguments about who has how many chips!

Automatic Blinds Posting

Configure small blind and big blind amounts with auto-posting functionality. The tracker automatically deducts blinds from the correct players based on position, following proper Texas Hold'em rules including heads-up blind posting.

Pot & Bet Calculator

Real-time pot calculation and current bet tracking. See the total pot size and current bet amount updated instantly as players bet, raise, call, or fold. Minimum raise enforcement ensures proper poker rules are followed.

Multiplayer Support

Connect multiple devices for seamless peer-to-peer gameplay. One player hosts a game and shares a 6-character room code. Other players join and all devices sync in real-time. Perfect for games where each player wants to see the action on their own device.

Digital Cards Display

Visual community cards for Texas Hold'em games. Toggle on to see flop, turn, and river cards displayed digitally with proper suit colors (red hearts/diamonds, black spades/clubs). Great for online games or reducing physical card handling.

Tournament Mode

Track button position, blinds, and betting rounds with ease. Move the dealer button after each hand, manage multiple betting streets (preflop, flop, turn, river), and use the "Empty Pot" feature to award chips to specific players when needed.

How to Use Live Poker Tracker

Single Player Mode

  1. Visit livepokerchips.com on any device
  2. Add players with their starting chip stacks (default: 1000 chips)
  3. Configure blinds (small blind and big blind amounts)
  4. Enable or disable auto-post blinds and digital cards
  5. Click "Start Round" to begin tracking your poker game
  6. Use action buttons (bet, raise, call, check, fold) to track gameplay
  7. Watch as the pot and player stacks update automatically
  8. Click "Next Street" to advance through flop, turn, and river
  9. Use "Move Button" to rotate dealer position after each hand

Multiplayer Mode

  1. Host clicks "Host New Game" on the multiplayer page
  2. Share the 6-character room code with other players
  3. Players enter the room code and click "Join Game"
  4. All devices redirect to the game room and sync automatically
  5. Host or any player can manage the game (add players, start rounds, etc.)
  6. All actions sync across all connected devices in real-time

Frequently Asked Questions

Is Live Poker Tracker really free?

Yes! Live Poker Tracker is 100% free with no hidden costs, subscriptions, or premium features. We built this tool for the poker community to enjoy home games without worrying about chip counting.

Do I need to download or install anything?

No downloads required! Live Poker Tracker runs entirely in your web browser. Just visit the website and start playing. It works on desktop, tablet, and mobile devices.

How does multiplayer mode work?

Multiplayer mode uses peer-to-peer connections, meaning your devices connect directly to each other without our servers storing any game data. One player hosts a game and shares a room code with others. All devices sync in real-time as the game progresses.

Can I use this for cash games or just tournaments?

Live Poker Tracker works perfectly for both cash games and tournaments! For cash games, track chip stacks and pots. For tournaments, use the automatic blinds feature and configure increasing blind levels manually as needed.

Does it work offline?

Single-player mode works offline once the page has loaded. Multiplayer mode requires an internet connection for devices to sync with each other.

How many players can join a game?

You can track up to 10 players at a poker table, which matches the maximum for most Texas Hold'em games. For larger tournaments with multiple tables, you can run separate instances of the tracker on different devices.

What poker variants does this support?

Live Poker Tracker is optimized for Texas Hold'em, the most popular poker variant. It tracks blinds, chip stacks, pots, and community cards. While you can use it for other variants, features like digital cards display are designed specifically for Hold'em.

Is my game data saved or stored anywhere?

Single-device sessions are saved locally in your browser so they can be restored after refresh. Multiplayer room state is kept in browser memory. Game data is not uploaded to our servers.

Can I install this as an app on my phone?

Yes! Live Poker Tracker is a Progressive Web App (PWA). On mobile devices, you can add it to your home screen for a native app-like experience. Just visit the site and use your browser's "Add to Home Screen" option.

What browsers are supported?

Live Poker Tracker works on all modern browsers including Chrome, Firefox, Safari, and Edge. For the best experience, we recommend using the latest version of your preferred browser.

How do I report a bug or request a feature?

We'd love to hear from you! Visit our GitHub repository to report issues or suggest new features.
